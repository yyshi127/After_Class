# AfterClass MVP 验收演示脚本

目标：用 20–30 分钟向机构负责人、校区管理员和老师演示商业 MVP 的真实运营闭环：校区建档 → 学生/家长/班级/老师配置 → 到托安全通知 → 作业批改与家长反馈 → 错题本与练习单 → 服务有效期/核算 → AI 与审计日志追溯。

## 演示前准备

1. 复制环境模板并填入真实部署值：`.env.example` → `.env`。
2. 执行迁移：`npm run db:migrate`。
3. 导入演示数据：`npm run db:seed`。
4. 启动系统：`npm run build && npm run start`。
5. 准备四类演示账号：总部/校区管理员、老师、家长、学生。

## 角色 1：管理员端运营配置

路径：`/admin`

1. 打开运营首页，说明多校区经营指标、到课率、作业发布、续费风险和 AI 日志入口。
2. 进入 `/admin/campuses`，展示校区列表与启停状态。
3. 进入 `/admin/classes` 与 `/admin/classes/assignments`，展示班级容量、时段、老师分配和跨校区隔离。
4. 进入 `/admin/students` 与 `/admin/guardians`，展示学生档案、身份证脱敏、家长绑定。
5. 进入 `/admin/billing` 与 `/admin/settlements`，展示内部收费/课消/老师费用/毛利只对管理员可见。

验收点：管理员能完成基础数据建档，跨校区数据隔离明确，敏感身份与财务数据不出现在家长/学生端。

## 角色 2：老师端晚辅执行

路径：`/teacher`

1. 打开今日托管，查看负责班级、学生到托状态、服务到期提醒。
2. 进入 `/teacher/photo-check-in`，演示拍照到托、家长安全通知链路。
3. 进入 `/teacher/homework-upload`，上传/选择作业图片。
4. 进入 `/teacher/homework-correction`，查看 AI 错因建议、错误区域确认、老师人工确认/订正。
5. 进入 `/teacher/practice-sheet`，演示从错题生成 Word 练习单草稿，老师确认后再发布。

验收点：AI 只生成草稿和建议，老师保留确认权；作业、错题、练习单形成学习闭环。

## 角色 3：家长端安全与学习反馈

路径：`/parent`

1. 打开家长首页，查看到托照片、安全状态、作业反馈摘要和服务有效期。
2. 进入 `/parent/homework-feedback`，查看已发布作业原图、批改结果、三段式反馈、错题摘要。
3. 使用家长 AI 助手查询“今天到托了吗”“作业完成了吗”“服务有效期到什么时候”。
4. 演示请假确认卡片：AI 只生成待确认动作，确认前不会通知老师。
5. 进入 `/parent/profile`，查看绑定孩子、通知设置、请假记录和安全服务有效期。

验收点：家长只看到安全、学习和服务有效期信息；不得展示余额、欠费、应收、已收、课消、教师费用、毛利。

## 角色 4：学生端学习入口

路径：`/student`

1. 打开今日任务，查看自己的完成进度、待办、待订正错题和鼓励语。
2. 进入 `/student/mistake-book`，查看只属于自己的错题卡片。
3. 演示 AI 讲解入口、同类题练习、拍照提问入口。

验收点：学生端只展示当前学生自己的任务和错题，不展示老师内部备注、AI 内部置信度、运营/财务数据。

## 运营追溯与合规收口

1. 进入 `/admin/ai-logs`，展示 AI 调用原始输入、意图、置信度、风险等级、确认状态、结果和失败原因。
2. 说明 `AuditLog` 覆盖敏感身份查看、数据导出、收费调整。
3. 打开 `docs/operations/logging-strategy.md`，说明应用日志、AI 日志、审计日志和错误日志分层。
4. 打开 `docs/operations/backup-and-restore.md`，说明每日备份、异地保存和恢复演练。

验收点：关键操作可追踪，AI 高风险动作可拒绝，涉及未成年人隐私默认最小化展示。

## 演示验收清单

- [ ] 四端入口可访问：管理员、老师、家长、学生。
- [ ] 校区、班级、学生、家长、老师分配链路可讲清。
- [ ] 到托拍照通知链路可演示。
- [ ] 作业上传、AI 建议、老师确认、家长反馈链路可演示。
- [ ] 错题本与 Word 练习单链路可演示。
- [ ] 家长端不展示内部财务字段。
- [ ] 学生端只展示本人数据。
- [ ] AI 日志和审计日志可追溯。
- [ ] 备份、迁移、日志策略具备部署说明。
